# Debtors Collector

Debtors age analysis, follow-up e-mails and bank matching for Sage Pastel companies, on Windows.

## Download

**[Download the latest version](https://github.com/Sublime1975/debtors-collector-releases/releases/latest)** — under *Assets*, choose `Debtors-Collector-Setup-<version>.exe`.

Once installed, Debtors Collector tells you when a newer version is out and updates when you press **Update now**.

## Windows says "Windows protected your PC"

The installer is not yet signed with a code-signing certificate, so Windows asks before running it the first time. Click **More info**, then **Run anyway**. Updates after that install without the question.

## Needs

- Windows 10 or 11
- Sage Pastel Partner on the same computer
